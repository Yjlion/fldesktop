fldesktop packages

Signed apt and pacman repositories for fldesktop, a Wayland desktop built with FLTK.

Two channels: stable has the tagged releases, devel is rebuilt from every change to main. Packages are signed with the key fldesktop-archive-keyring.asc, fingerprint
4A49 3D03 7B26 F761 9470 F830 60F9 733B 07BD AA7B.

Debian 13 (trixie), amd64 and arm64

sudo curl -fsSLo /usr/share/keyrings/fldesktop-archive-keyring.asc \
  https://yjlion.github.io/fldesktop/fldesktop-archive-keyring.asc
echo "deb [signed-by=/usr/share/keyrings/fldesktop-archive-keyring.asc] https://yjlion.github.io/fldesktop/debian trixie main" \
  | sudo tee /etc/apt/sources.list.d/fldesktop.list
sudo apt update
sudo apt install fldesktop fldesktop-greeter fldesktop-archive-keyring

For the development builds use the suite trixie-devel instead of trixie.

Arch Linux, x86_64

curl -fsSLO https://yjlion.github.io/fldesktop/fldesktop-archive-keyring.asc
sudo pacman-key --add fldesktop-archive-keyring.asc
sudo pacman-key --lsign-key 4A493D037B26F7619470F83060F9733B07BDAA7B

Then add to /etc/pacman.conf:

[fldesktop]
Server = https://yjlion.github.io/fldesktop/arch/stable/$arch
sudo pacman -Syu fldesktop fldesktop-greeter fldesktop-keyring

For the development builds use arch/devel/$arch.
